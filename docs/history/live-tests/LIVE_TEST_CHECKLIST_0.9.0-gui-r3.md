# Один живой тест DDS Installer 0.9.0-gui-r3

**Не удалять рабочую установку DDS, SQLite или DDS_Data ради проверки.**

1. Запустить новый `DDSSetup.exe` обычным двойным щелчком. Проверить иконку, русский текст, три страницы, сохранённый дизайн.
2. На MAINFRAME с установленным DDS должен отображаться его реальный старый путь; его перенос заблокирован. `Program Files\DDS` — стандарт именно новой установки. Полная проверка нового пути возможна только в согласованном сценарии, где Companion отсутствует; старую установку заранее не удалять.
3. Оставить нужные компоненты и выбрать, создавать ли ярлык. Закрыть старый Companion перед согласованной установкой, сохранить черновики/завершить звонок Discord. Нажать «Установить».
4. Проверить, что исправные компоненты не переустановлены; новые устанавливаются последовательно, без ручного закрытия Discord и включения DDS Plugin. При включённом UAC для новой папки Companion ожидается запрос прав; отмена должна дать понятный отказ. При отключённом UAC Windows не показывает этот запрос.
5. Финальная страница должна показывать состояние файлов по четырём компонентам. До «Завершить» выбранные пользовательские приложения не должны запускаться.
6. Выбрать независимые флажки «Запустить Discord» / «Запустить DDS Companion», нажать «Завершить». Окно Installer должно закрыться; открываются только выбранные приложения. «Закрыть»/крестик на финальной странице не запускают ничего.
7. Если ярлык был выбран, проверить `DDS.lnk` на реальном рабочем столе: стабильный DDS.exe, фирменная иконка, без дублей. При снятой галочке новый ярлык не создаётся; прежний не удаляется.
8. После выбранного запуска проверить Companion, доступность прежней библиотеки/архива и SQLite, а также Plugin heartbeat/статусы. Только этот реальный результат может подтвердить работоспособность всей цепочки.

При ошибке прислать скрин страницы и «Подробности». Не продолжать вручную удалять компоненты или архив.

Часть проверок нового Program Files пути нельзя считать пройденной по успешному no-op на существующей установке. Repair/Uninstall/перенос установки в этом кандидате не проверяются.
