# Один реальный Windows тест исправления

Использовать компьютер, где уже наблюдались найденные файлы BetterDiscord/DDS Plugin без работающего BetterDiscord. Предварительно удалять или искусственно повреждать рабочие компоненты не требуется. Сам тест установки запускается пользователем после отдельного решения.

1. Проверить SHA-256 DDSSetup.exe по SHA256_0.9.0-gui-r4.txt. Запустить обычным двойным щелчком. Не вводить вручную команды изменения Discord/реестра.
2. На «Настройка»: Discord уже найден; BetterDiscord — «Будет восстановлено внедрение»; DDS Plugin — проверка/включение. Существующий Companion должен сохранить путь. Запомнить состояния посторонних плагинов/тем; сохранить черновики и выйти из звонка.
3. Нажать «Установить». Installer сам закрывает Discord, выполняет повторный CLI install для BetterDiscord, проверяет loader, DDS Plugin и включает только DDS. Убедиться, что Discord не просит вручную закрыть себя и не остаётся открытым в середине установки. Исправный Discord повторно не устанавливается.
4. На «Завершение» проверить результат файлов. Оставить две галочки, нажать «Завершить». До закрытия GUI пользовательские приложения запускаться не должны.
5. Дождаться Discord и Companion (проверка после выхода мастера ограничена общим контекстом 2 минуты). В Discord должны появиться настройки BetterDiscord и включённый DDS; остальные addon-настройки должны сохраниться.
6. Проверить %TEMP%\DDS_Installer_PostLaunch_Status.txt: дата соответствует этому запуску, Discord ЗАПУЩЕНО, BetterDiscord/DDS Plugin РАБОТАЕТ по свежему heartbeat. Heartbeat: %APPDATA%\BetterDiscord\DDS_Data\plugin_heartbeat.json; RUNNING и updatedAt новее этого запуска, версия совпадает с файлом DDS Plugin.
7. В Companion открыть статус и подтвердить обнаружение работающего DDS Plugin. Проверить сохранность существующего архива и настроек. Если Companion отсутствовал, проверить первый запуск, DataRoot/SQLite и фактическую выбранную папку установки.

Полный основной сценарий PASS — только после п.5–7. Если новый heartbeat отсутствует/BD не загрузился/Companion не видит Plugin, сохранить диагностический текст: результат PARTIAL, не полный PASS.

Галочки независимы: если Discord намеренно не запускается, runtime BD/DDS остаётся НЕ ПРОВЕРЯЛОСЬ, это не ошибка файловой установки. Cancel/X не запускают приложения. Для краткого основного теста не требуется заново устанавливать всё ради проверки каждого сочетания галочек — их логика покрыта целевыми тестами.
