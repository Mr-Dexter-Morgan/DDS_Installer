# DDS Installer 0.9.0-gui-r2 — изменения

Дата: 19.10.2026, Москва.

- Продолжение точных исходников 0.9.0-gui-r1; проект не переписывался.
- Системная Program Files как стандарт для новой установки; выбор пользовательского пути.
- Явный отказ от несанкционированной миграции существующей установки и пересечения программного пути с DataRoot.
- Отдельный UAC Apply, asInvoker GUI, права владельца новой папки для действующего Updater.
- Обнаружение Program Files и зарегистрированного пользовательского пути при последующих запусках, даже когда Companion закрыт.
- Настоящий опциональный ярлык стабильного launcher, защита от дублей и чужого DDS.lnk, учёт принадлежности интеграции.
- Сохранён порядок Discord → BetterDiscord → DDS Plugin → Companion; скрыты консоли вспомогательных команд, выбранный DDS Plugin включается без изменения остальных плагинов.
- Журнал вынесен в «Подробности», подключён фактический прогресс скачивания.
- Итоги по компонентам, независимый запуск после выхода Installer; убрано длительное ожидание heartbeat внутри завершающего helper.
- Один старый тест защиты внешнего запуска адаптирован к нативной Windows: исходный тест ожидал только Linux-отказ.
- Новые целевые проверки пути, сохранности архива, ошибки ACL, ярлыка, прав владельца и финальных галочек запуска.

Прежние ревизии и их evidence не изменены. GitHub commit/merge/tag/Release не выполнялись.
