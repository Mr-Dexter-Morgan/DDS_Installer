# Изменения gui-r4 — 21.10.2026

- Исправлены два пропуска обнаруженного BetterDiscord: selectedSetupPlan и executeSelectedFirstSetup больше не считают StateOK основанием пропустить выбранное повторное внедрение.
- Для установки DDS обязательна выбранная операция BetterDiscord. Исправные Discord и Companion сохраняются.
- Повторный официальный bdcli --silent install --channel stable запускается после автоматического закрытия Discord. После команды, включая ошибку, Discord повторно закрывается при необходимости. Shutdown ограничен контекстом 30 секунд и сохраняет graceful/force fallback r3.
- Проверяется официальный CLI v1 loader текущей установки Stable: app/index.js, package.json, сохранённый betterdiscord.app.asar, ядро BD и отсутствие затеняющего app.asar. Это файловая проверка, не runtime PASS.
- Существующий DDS Plugin проверяется по точному пути, @name и версии и включается независимо от наличия файла; состояния других плагинов не изменяются. Запись состояния проверяется чтением.
- В существующий post-Finish обработчик добавлены раздельные статусы запуска, внедрения и работы. Heartbeat должен соответствовать установленной версии DDS и иметь время не раньше текущего запуска после выхода мастера; старые/STOPPED/будущие записи не принимаются.
- Сохранены три страницы GUI, оформление, asInvoker/UAC-политика r3, пути приложения/данных, независимые галочки и запрет запуска при Cancel/X. Companion и Plugin не менялись.

Наблюдение Максима: после Setup обнаруженные BetterDiscord/Plugin не заработали. Точная первопричина UNKNOWN; подтверждён дефект Installer, позволяющий пропустить восстановление по наличию файлов. Нельзя утверждать, что сам дефект на его машине уже исправлен живым тестом.
