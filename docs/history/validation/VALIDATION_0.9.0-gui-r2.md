## Границы доказанного

Не выполнялась установка/переустановка на MAINFRAME. Не вызывался UAC Apply для Program Files и не создавался ярлык на настоящем рабочем столе. Рабочие Discord, Plugin, Companion и архив не менялись. Совместимость обновления проверена по прежнему формату пакета/указателя и правам на тестовой папке; реальное обновление/откат новой Program Files установки не выполнялись.

Детектор гонок не запускался: доступный нативный Go установлен с CGO_ENABLED=0. Linux PASS предыдущих кандидатов не приписывается этой ревизии.

Полный GUI Setup, UAC-переход на реальной установке, финальный запуск выбранных приложений и сохранность реального архива остаются **USER WINDOWS LIVE PENDING**. Repair/Portable Setup/Uninstall не объявляются реализованными или проверенными.

Исторический Go-набор r1 сначала выявил один тест, предполагающий Linux-отказ внешнего запуска; он адаптирован к реальному Windows-отказу отсутствующего файла. В ACL-тесте использован .NET-readback вместо `Get-Acl`, поскольку модуль PowerShell Security в унаследованной среде разработки не загрузился. В итоге целевые проверки и финальный полный набор PASS; неуспешные попытки не считаются успешными проверками.
