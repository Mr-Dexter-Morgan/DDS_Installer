# DDS Installer 0.9.0-gui-r4

CANDIDATE / AUTOMATED PASS / WINDOWS LIVE PENDING / NOT RELEASED. База — точный принятый gui-r3, не изменён.

Запусти DDSSetup.exe обычным двойным щелчком. GUI: Настройка → Установка → Завершение. Закрой звонок и сохрани черновики: при нажатии «Установить» Discord закроется автоматически, при необходимости с принудительным завершением после ограниченного ожидания.

BetterDiscord необходимо оставить выбранным для установки DDS Plugin или Companion. Даже обнаруженный BetterDiscord проходит повторное официальное внедрение. Исправный Discord не скачивается/не устанавливается повторно. Существующий корректный DDS Plugin проверяется и включается; меняется только ключ DDS в plugins.json. Остальные плагины, темы и настройки сохраняются. Открытие мастера и просмотр состояния ничего не ремонтируют.

Новый Companion размещается по принятому r3-контракту в системной Program Files\DDS (обычно C:\Program Files\DDS); существующий исправный Companion сохраняет свой путь. Пользовательские данные остаются в %LOCALAPPDATA%\DDS_Companion. Миграции и очистки данных нет.

На финальной странице независимо выбери запуск Discord/Companion и нажми «Завершить». Приложения запускаются существующим временным обработчиком только после выхода GUI. Закрытие крестиком/кнопкой «Закрыть» ничего не запускает.

После запуска выполняется ограниченная проверка процессов, официального loader BetterDiscord и heartbeat DDS новее текущего запуска. Статус: %TEMP%\DDS_Installer_PostLaunch_Status.txt. Если работа не подтверждена, обработчик покажет диагностическое сообщение; установленные файлы не удаляются. Если запуск Discord не выбран, отсутствие runtime-проверки не является ошибкой установки. Если обе галочки сняты, обработчик не запускается, а старый status-файл не относится к этому запуску (проверяй дату).

Наличие loader доказывает внедрение файлов; процесс доказывает запуск; только новый heartbeat доказывает выполнение DDS Plugin и косвенно загрузку BetterDiscord. Факт обнаружения Plugin самим Companion нужно проверить в его интерфейсе. Автоматически полный RUNTIME_READY/LIVE PASS не объявляется.

Это точечный Setup-патч, не общий Repair DDS, Uninstall или Portable Setup. Внешние установщики требуют доступа к своим официальным источникам; актуальность кэшированного CLI онлайн не гарантируется. Несовместимый с CLI v1 loader блокируется с диагностикой, без ложного успеха.
