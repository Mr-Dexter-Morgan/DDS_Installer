# DDS Installer 0.9.0-gui-r3

Исправление блокировки обычного запуска при отключённом UAC (EnableLUA=0). Настройки Windows не меняются. GUI и запуск после Finish используют существующие права текущего пользователя; при отключённом UAC у администратора они повышены. При включённом UAC прежний запрет запуска повышенного GUI сохраняется. Остальное поведение GUI r2 сохранено.

Запуск: обычный двойной щелчок DDSSetup.exe. Существующую установку и архив не удалять. Полная установка через GUI ещё не подтверждена.
