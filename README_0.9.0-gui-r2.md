# DDS Installer 0.9.0-gui-r2

**Кандидат для одного живого теста Windows. Не релиз; полная установка через GUI ещё не подтверждена.**

Запуск: обычным двойным щелчком по `DDSSetup.exe`, без «Запустить от имени администратора».
Установщик запросит UAC сам, если потребуется размещение нового Companion.

## Изменения

- Сохранены утверждённые три страницы, белая шапка, синий фон, маскот, русские подписи и исходная встроенная DDS.ico.
- Для новой установки программные файлы по умолчанию размещаются в системной `Program Files\DDS`. Путь можно изменить вручную или через «Обзор»; родительская папка должна существовать.
- Обнаруженная существующая установка сохраняет свой путь. Поле заблокировано: автоматического переноса старого `%LOCALAPPDATA%\DDS` нет. Её данные и файлы не перемещаются.
- Архив, SQLite, кэш и настройки остаются в `%LOCALAPPDATA%\DDS_Companion`.
- «Создать ярлык на рабочем столе» действительно управляет созданием `DDS.lnk`. Ярлык использует стабильный `DDS.exe` и его фирменную иконку; повтор не создаёт копии. Снятая галочка не удаляет уже существующий ярлык.
- Инсталлятор сохраняет принадлежность своей интеграции в `%LOCALAPPDATA%\DDS_Installer\installed.json` и `HKCU\Software\DDS\Installer`. Это не регистрация готового Uninstall и не второй автозапуск.
- Установка повторно использует проверенный механизм r3, включая управление Discord и включение только DDS Plugin. Исправные программные компоненты не переустанавливаются.
- Во время скачивания показываются фактические байты и процент при известном размере. Технический журнал доступен через «Подробности».
- На странице завершения показаны состояния файлов четырёх компонентов. Две галочки запуска независимы; запуск происходит только по «Завершить» после выхода основного Installer. Крестик/«Закрыть» не запускают приложения.
- Завершающий процесс сразу уходит после передачи запуска; он не держит Installer ещё 90 секунд и не заявляет `RUNTIME_READY` без наблюдения runtime.

## Права и совместимость Updater

GUI и операции пользовательского профиля работают без повышения прав. Встроенный манифест `asInvoker` исключает автоматическое повышение всего GUI из-за имени DDSSetup. Отдельный шаг Apply через Windows `runas` размещает только новый проверенный каталог Companion.

Для совместимости с действующим Updater 0.8.5 новой папке DDS и её содержимому выдаётся наследуемое право **Modify только SID установившего пользователя**. Права самой Program Files и других приложений не меняются. Таким образом, новая папка DDS является каталогом программы, обслуживаемым этим пользователем, и не имеет обычного запрета записи для него. Это сознательная политика персональной установки; работающий Companion и его процесс запуска не повышаются до администратора. Для обновления сохраняется прежний контракт `DDS.exe` / `DDSUpdater.exe` / `current.json` / `versions/<version>/DDSApp.exe`.

Миграция существующей установки, полноценные Repair, Portable Setup и Uninstall остаются отдельными задачами. Их готовность не заявляется.

Инструкция проверки: `LIVE_TEST_CHECKLIST_0.9.0-gui-r2.md`.
