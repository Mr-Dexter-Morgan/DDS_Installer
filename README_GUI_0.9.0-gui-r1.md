# DDS Installer 0.9.0-gui-r1 — GUI-кандидат

Статус: **WINDOWS GUI CANDIDATE / AUTOMATED PASS / WINDOWS GUI LIVE PENDING / NOT RELEASED**.

Основа: проверенный пользователем на MAINFRAME Installer 0.8.0-r3 (консольный RUNTIME_READY от 2026-10-19). Исходный архив r3 сохранён без изменений.

## Что нового

- Один `DDSSetup.exe` — нативное окно Windows вместо консоли, без стороннего WebView или установки GUI-библиотек.
- Тёмно-синяя визуальная тема с белой шапкой, фирменной DDS.ico, маскотом и полным названием `DDS - Discord Data Snatcher`.
- Русские шаги: **Настройка → Установка → Завершение**.
- На первой странице 4 интерактивных чекбокса: Discord, BetterDiscord, DDS Plugin, DDS Companion. По умолчанию выбраны все. Если отсутствуют зависимости выбранного компонента, установка не стартует до исправления выбора.
- Установленные здоровые компоненты не перезаписываются. Для неопределённых/частичных состояний, как и прежде, первичная установка блокируется — отдельный Repair в этой версии не реализован.
- Путь Companion отображается честно и фиксирован текущим контрактом: `%LOCALAPPDATA%\DDS`. Смена пути в этой версии не поддерживается.
- Этапы загрузки и установки выполняет проверенное ядро r3: Acquire → Verify → Stage → Apply. Во время установки Installer управляет закрытием Discord.
- На финальной странице два независимых чекбокса запуска. Только **кнопка «Завершить»** запускает выбранные приложения через отдельный процесс, ожидающий завершения Installer. Крестик или «Закрыть» не запускают ничего. Если соответствующее приложение не установлено, флажок запуска неактивен.
- Прежний запуск приложений до закрытия Setup не используется. Проверка heartbeat и SQLite после запуска записывается в `%TEMP%\DDS_Installer_PostLaunch_Status.txt` при выборе обоих приложений; GUI не заявляет RUNTIME_READY до проверки.
- Явное предупреждение о закрытии Discord перед началом установки.

## Как проверять безопасно

1. Распаковать ZIP в отдельную папку.
2. Запустить `DDSSetup.exe`. Если DDS уже установлен и здоров, ничего удалять заранее **не нужно**: можно посмотреть GUI и закрыть его, не начиная установку.
3. Если требуется полная переустановка, решать отдельно после визуальной проверки GUI. Архив `%LOCALAPPDATA%\DDS_Companion`, SQLite и `DDS_Data` не следует удалять.

## Ограничения

- Интерфейс собран кросс-компиляцией под Windows x64; фактический рендер и взаимодействие с GUI на Windows ещё **не подтверждены**.
- Нельзя считать кнопку «Завершить» эквивалентом подтверждённого живого heartbeat: запуск и проверка теперь происходят ПОСЛЕ закрытия GUI.
- Нет реализации полного Repair/Portable/Uninstall; основной сценарий — первичная установленная конфигурация, как в r3.
- Установщик не имеет цифровой подписи издателя; Windows может показывать предупреждение SmartScreen.
